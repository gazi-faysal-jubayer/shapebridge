# Samples

Small models for manual checks and smoke tests. All of them were generated by this project and are released under Apache-2.0 with the rest of the repo.

| File | Made by | Notes |
|---|---|---|
| `plate.step` | `node scripts/make-samples.mjs` | 40 × 30 × 10 mm plate with a Ø12 hole, exact B-rep |
| `plate.stl` | same | binary tessellation of the same plate |
| `bracket.sbridge.json` | copy of `sampleDoc` in `src/model/doc.ts` | open it in ShapeBridge to get the parametric designer |

Adding a sample: keep it under 200 KB, make it yourself (or use a file with a permissive licence and record the source here), and add a smoke test.
