# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be welcoming, patient and respectful. People come from every country, skill level and background.
- Critique ideas and code, never people.
- No harassment, insults, sexualised language or imagery, doxxing, or sustained disruption.
- Assume good faith. Ask before assuming.

## Scope

All project spaces (issues, PRs, discussions, chat) and any public space where someone represents the project.

## Enforcement

Report incidents privately to the maintainer through GitHub (profile → *Contact*), or by email to the address on the maintainer's GitHub profile. Reports are handled confidentially. Consequences follow the Covenant's ladder: correction, warning, temporary ban, permanent ban.
